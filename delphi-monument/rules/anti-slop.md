# Anti-slop: what never to do in a Monument screen

AI-generated UI is recognisable by a small set of defaults. Removing them is not enough: last time we replaced them with "the next layer" of clichés that the lists did not have yet. This file lists both layers. The check script catches the mechanical ones; the rest is on you.

## Layer 1: the classic signs
| Never | Monument instead |
|---|---|
| Purple-blue gradient hero, glowing blobs, grid or dot pattern behind content | flat stone |
| Glass cards, backdrop blur | rules and bays; slabs only for the key figure and the AI voice |
| Rounded corners everywhere, soft shadows | sharp corners, no shadows |
| Inter, Geist, Space Grotesk, Poppins, Montserrat, Roboto | Forum (inscription only) + Literata |
| Three identical feature cards in a row | real content in the composition of that screen type |
| Stock icon sets (Lucide, Heroicons, Tabler, Phosphor), emoji as markers | words; museum labels |
| "Get started →", "Узнать больше", arrows as decoration | a verb that says what happens |
| A three-word slogan headline | the thought of the screen with numbers (thesis) |
| Buzzwords: революционный, бесшовный, на базе ИИ, раскройте потенциал | what it does, concretely |
| "Это не X, это Y" | a plain statement |

## Layer 2: the signs we fell into ourselves (do not repeat)
| Never | Why | Instead |
|---|---|---|
| Near-black + one neon accent + glowing button, breathing animation | the 2025 "premium AI" look | slate stone, matte paint, ink buttons, no glow |
| Small grey monospace labels in caps with letter-spacing everywhere | the next-layer replacement of the classic eyebrow | museum labels in Literata, normal case, 15 px+ |
| Condensed caps headline with one italic serif word in another colour | the 2024-25 "editorial AI" headline | one Forum inscription with interpuncts, thesis below |
| Corner brackets, chamfered corners, HUD ticks, coordinates in the footer | sci-fi genre costume | rules, cornice, stepped base |
| Roman numerals or 01/02/03 on sections | fake structure | museum labels without numbers |
| "Big number + sparkline + LIVE" card on the right of a text block | the default AI dashboard hero | key figure as a full-width orchid band above the inscription |
| **Text on the left, coloured card on the right** | the most common layout template | the composition of the screen type (rules §5) |
| Pastel colour tiles with a huge black number | "Dribbble 2024" neo-brutalist bento | deep pigment slab with light text, one per role per screen |
| Dark slab with a coloured top edge | reads as a generic dark UI card | pigment slab |
| Warm cream background + serif + terracotta | the "editorial" AI template | neutral stone (night) or neutral paper |
| Background tinted toward the accent colour | everything-in-one-hue generator look | neutral stone |
| Marble textures, veins, noise, light pools, gradients | decoration that fights the data and reads as a "luxury template" | flat stone |
| Ornament as border or wallpaper (meander strip, rosettes, frieze) | "Greek restaurant" | signs only as working elements (meander = progress, colonnade = chart) |
| Delphi/oracle props: Greek maxims, "Спросите оракула" | theme costume | plain product language |
| Chat bubbles with avatars | the default chat template | the protocol: question as heading, answer as exhibit |
| Paint on buttons | colour loses meaning | ink buttons; paint = data and AI voice |
| Many meanders or pink columns "for style" | a sign turns into a theme | meander ≤ 2 per screen, columns marble/bronze only |
| Every text the same small size | the strongest slop signal for this team | big bold key number, thesis and actions |

## The test before "done"
Put your screen next to three AI-generated dashboards in your head. If someone could swap your colours and fonts and it would become one of them, the composition is a template: rebuild it in the composition of its screen type.
