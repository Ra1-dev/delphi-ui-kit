# Delphi Monument

Стиль команды Delphi для хакатонных MVP: «музей данных». Тёмный камень, надпись Forum с интерпунктами, Literata, плиты глубокой орхидеи и бронзы, меандр как шкала прогресса, колоннада как столбчатый график, музейные подписи и пометки ИИ на полях.

## Что внутри
| Папка | Что это |
|---|---|
| `SKILL.md` | скилл Claude Code `delphi-monument` |
| `AGENTS.md` | то же для Cursor, Codex и других агентов |
| `rules/MONUMENT.md` | правила стиля: слои, цвет, шрифты, композиции экранов, знаки, состояния |
| `rules/anti-slop.md` | что нельзя делать, два слоя признаков ИИ-слопа |
| `styles/monument.css` | токены (ночь и бумага) и базовые классы |
| `styles/theme.css` | тема Tailwind v4: отключает стандартные цвета, скругления, тени, шрифты |
| `fonts/` | Forum и Literata офлайн, с казахским |
| `components/` | React-компоненты: надпись, меандр, колоннада, плиты, пометки, поля, состояния |
| `vanilla/monument.js` | те же знаки для HTML-страниц без React |
| `examples/` | эталонные экраны на React: витрина и мастерская |
| `references/` | эталонные HTML-прототипы: дашборд, чат, загрузка, мобильная форма, мастерская, отчёт, лёгкий вариант |
| `scripts/check-monument.mjs` | проверка на нарушения |
| `proposals/README.md` | как новый компонент попадает в набор |
| `prompts/restyle.md` | готовый промпт для агента: перевести проект на Монумент, с переключателем ЗАМЕНА / ПРОСМОТР |

## Установка скилла для Claude Code
```bash
cp -r delphi-monument ~/.claude/skills/delphi-monument
```
Дальше в любом проекте достаточно попросить агента собрать экран в стиле Delphi или «Монумент».

Перевести существующий проект целиком: промпт [`prompts/restyle.md`](prompts/restyle.md). В нём один переключатель. `ЗАМЕНА` удаляет старый дизайн и делает Монумент единственным, в ветке `redesign/monument`. `ПРОСМОТР` не трогает проект и собирает страницы для просмотра в копии. Без указания режима скилл работает как `ЗАМЕНА`.

## Проверка проекта
```bash
node monument/scripts/check-monument.mjs src
```
