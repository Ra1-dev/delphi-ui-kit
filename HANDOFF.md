# Handoff: Delphi UI kit

## Кто и зачем
Хакатонная команда **Delphi**. За 24 часа нужен MVP; бэкенд у команды сильный, а фронт собирают ИИ-агенты, и он выглядит сгенерированным. Цель — **единый стандарт и агентный набор**: агент получает правила, токены и компоненты и сам собирает интерфейс, который выглядит серьёзно, необычно и **не похож на ИИ-слоп**, а судьи узнают по нему команду. Delphi — просто название команды, продукта нет; стиль ложится на любые хакатонные темы.

Стек: React 18+, TypeScript, Tailwind 4.1+ (на 4.0.x сборка падает). Веб и мобильный веб (PWA). Языки: русский и казахский, **шрифты обязаны поддерживать ә ғ қ ң ө ұ ү һ і**.

Репозиторий: `C:\Users\Admin\Desktop\projects\delphi-ui-kit`, приватный `github.com/Ra1-dev/delphi-ui-kit`, ветка `main`.

## Единый стандарт: «Монумент»
Всё лежит в `delphi-monument/` (скилл Claude Code `delphi-monument`). Других стилей в репозитории нет: прежний набор Pythia (`delphi-kit/`) и все промежуточные прототипы удалены 5 ноября 2026 по решению пользователя.

Суть стиля (подробно в `delphi-monument/rules/MONUMENT.md`):
- «Музей данных»: тёмный сланец `#14171B` основной темой, бумага `#F4F3EF` для документов, отчётов и лёгкого варианта.
- Шрифты: **Forum** (одна надпись на экран прописными с интерпунктами бронзой, имя приложения) и **Literata** (всё остальное). Значимое крупно и жирно, ничего мельче 14 px.
- Цвет по ролям: **орхидея** — данные, на которые смотреть; **бронза** — голос ИИ и прогноз; **золото** — предупреждения; красный — ошибки. Кнопки тушью, краска на кнопках запрещена.
- **Плиты-пигмент**: глубокая орхидея `#9B3590` и бронза `#8C5524` со светлым текстом, не больше одной каждого цвета на экран.
- **Переосмысленные греческие знаки, которые работают**: меандр = шкала прогресса (≤ 2 на экран), колоннада = столбчатый график (3–10 значений, абака-линия = значение), карниз под шапкой, ступенчатое основание, пометки ИИ на полях, музейные подписи «что · откуда · когда».
- **Раскладка «Ордер»**: сетка 12 колонок, отсеки разделены линейками, а не карточками. У каждого типа экрана своя композиция (дашборд, чат-протокол, загрузка с результатом, мобильная форма, отчёт); «текст слева, карточка справа» запрещено.
- **Два слоя**: «Витрина» (то, что видят судьи: полный Монумент) и «Мастерская» (внутренние экраны и документы: плотно, без надписи, плит и знаков). **Лёгкий вариант** для несерьёзных тем: бумага, без греческих знаков.

Состав `delphi-monument/`: `SKILL.md`, `AGENTS.md`, `README.md`, `rules/MONUMENT.md`, `rules/anti-slop.md` (два слоя признаков слопа, включая те, в которые мы попадали сами), `styles/monument.css` (токены и классы `m-*`), `styles/theme.css` (Tailwind v4 без стандартных цветов, скруглений, теней, шрифтов), `fonts/` (Forum + Literata офлайн), `components/` (React), `vanilla/monument.js` (знаки без React), `examples/` (DashboardScreen, WorkshopScreen), `references/` (три HTML-прототипа: дашборд; чат, загрузка, мобильная форма на казахском; мастерская, отчёт, лёгкий вариант), `scripts/check-monument.mjs`, `proposals/README.md`.

Опубликованные прототипы: [Дашборд](https://claude.ai/artifact/C3N7VmoB1AfDVqQfk5DaYC), [Чат, загрузка, мобильная](https://claude.ai/artifact/9E4XrC8N9Qzw6MiUDNY2M7), [Мастерская, отчёт, лёгкий вариант](https://claude.ai/artifact/MtpsUwUfLBm1vKQoP1wpM4). Их исходники теперь только в `delphi-monument/references/`; чтобы обновить публикацию, передавайте её URL.

Проверено: в `delphi-playground` набор установлен как в реальный проект (`src/monument/`, `src/monument.css`); `npm run build` (строгий TS + Vite) проходит, `npm run check` даёт 0 находок; экраны сняты на ночи, бумаге и в мастерской; vanilla-скрипт проверен на отдельной HTML-странице.

## Уроки прошлых итераций (почему не делаем иначе)
- **Pythia** (почти чёрный фон, оранжевый со свечением, Oswald прописными с курсивным словом, моно-подписи, засечки и срезанные углы) после честного разбора читалась как продвинутый ИИ-дизайн 2025 года. Мы вычищали признаки по спискам и ставили на их место признаки «следующего слоя».
- **Эпиграфика с прожилками** (мрамор, киноварь, орнаменты, фонарь) скатилась в «элегантный шаблон»: свадьба, салон, люкс-тема. Киноварь читалась как ошибка, лазурит с золотом — как флаг Казахстана и Греция, шумовые прожилки — как дым.
- Пастельные плиты и «тёмная плита с цветной кромкой» читались как бенто и Dribbble 2024.
- Общий вывод: рукотворный вид дают главенство содержания, своя композиция у каждого типа экрана и знаки, которые работают, а не декор и не перебор палитр.

## Как работать с этим пользователем
- Пишет по-русски, любит спорить, просит не соглашаться автоматически и задавать вопросы. Модель склонна к среднему и к тихому «редакционному» минимализму; пользователь его не хочет.
- Главный фильтр: у варианта не должно быть узнаваемой чужой ассоциации. Называть ассоциацию до показа.
- Хочет видеть варианты вживую в HTML с переключателями, а не описания. Когда не может сформулировать желание, помогают названные гипотезы на выбор.
- Ценит честность: прямо говорить, насколько результат слопный, с оценкой.
- Перед «готово» проверять в браузере или безголовым Chrome; локальный `python -m http.server` отдаёт страницы без кодировки, для просмотра добавлять `<meta charset="utf-8">`.
- Коммитить и пушить только по просьбе.
